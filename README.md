# 😈 Devil Runs the Line

A fast-paced 2D arcade game where a fearless devil races across a dangerous world, dodging obstacles and conquering increasingly challenging environments.

## 🎮 About the Game


**Devil Runs the Line** is a full-fledged 2D game built around a simple idea: **keep moving and overcome everything in your path**.

You control a devil sprite traveling across a 2D plane filled with dynamic obstacles. From speeding vehicles to massive trains and other hazards, every moment demands quick reactions and precise movement.

Your goal is simple:

> **Go as far as you can. Conquer every obstacle. Never stop running.**

## ✨ Features

* 😈 **Playable Devil Character**
  Control a custom devil sprite as it travels through the game world.

* 🏃 **Fast-Paced 2D Gameplay**
  Navigate through a continuously moving 2D environment.

* 🚗 **Dynamic Obstacles**
  Avoid vehicles, barriers, and other objects standing in your way.

* 🚂 **Train Obstacles**
  Time your movements carefully to survive encounters with moving trains.

* 🎯 **Obstacle Conquering**
  Successfully overcome obstacles and continue your journey.

* 📈 **Increasing Challenge**
  The game becomes progressively more difficult as you travel farther.

* 🏆 **Score-Based Gameplay**
  Try to beat your previous distance and achieve a higher score.

* 🎨 **Custom 2D Visuals**
  A stylized game world centered around a unique devil character.

* ⚡ **Responsive Controls**
  Designed around quick reactions and precise movement.

## 🕹️ Gameplay

The devil continuously travels through the 2D world while obstacles appear in its path.

The player must:

1. Control the devil's movement.
2. Watch for incoming obstacles.
3. Time jumps or movements carefully.
4. Avoid collisions.
5. Continue traveling as far as possible.
6. Beat your previous high score.

The further you travel, the more challenging the game becomes.

## 🗺️ The World

The game takes place on a dangerous 2D journey filled with different obstacles and environments.

Possible obstacles include:

* 🚗 Cars and other vehicles
* 🚂 Moving trains
* 🧱 Barriers
* ⚠️ Hazardous objects
* 🌋 Environmental dangers
* 🔥 Other challenges encountered along the journey

Each obstacle requires the player to react quickly and adapt their strategy.

## 🏆 Objective

The main objective is to achieve the **highest possible score** by surviving for as long as possible.

Challenge yourself to:

* Travel farther than before.
* Avoid more obstacles.
* Improve your reaction time.
* Set a new personal record.
* Become the ultimate obstacle-conquering devil.

## 💻 Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project directory:

```bash
cd <project-folder>
```

Install the required dependencies:

```bash

```

Run the game:

```bash
python main.py
```
